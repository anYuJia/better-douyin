# 赞助名单

感谢每一位支持 better-douyin 的伙伴。此文件是赞助名单的维护源，编辑表格后运行：

```bash
npm run docs:sponsors
```

脚本会按照累计赞助金额从高到低排序，并同步更新根目录 `README.md`。同金额的赞助人保持表格中的原始顺序。

`头像背景色` 是生成赞助卡片图片时使用的可选字段；不需要调整视觉效果时可以留空。
